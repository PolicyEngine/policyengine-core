Uprating metadata can name a statutory base: with `base: {period, value}`, uprating computes each projected value as the base amount plus the increase the index implies over the base period, rounding that increase rather than the uprated amount. Base mode computes the increase exactly on the decimals the inputs print as, rounds an exact half up, and allows for float error only when an input is a computed float rather than an int or a decimal of at most 15 significant digits. `base.floor: true` keeps the index ratio at or above 1, for statutes that add the percentage (if any) by which an index exceeds its base-year level.
