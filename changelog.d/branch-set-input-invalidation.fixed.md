Simulation.set_input on a branch now drops the values the branch holds that may have been calculated from the value it replaces (every stored array carries a sequence number, and each simulation records what its values may have been calculated from), so a value the parent calculated before branching no longer shadows the branch's input. Simulation.derivative keeps inputs set after the simulation was built. An input a formula sets for the period it is calculating is no longer overwritten by the formula's result, and dump_simulation on a branch dumps the branch's own values (it read the default branch's, so the dump could not be restored).
