Persons joined to groups from a dataset now land in the group their ID names even when a group with no members sorts before theirs, and IDs of different dtypes match by value; an ID that names no declared group, or a repeated group ID, now raises instead of silently picking a group. Datasets with no role column now give every person (not every group) the default role, in every dataset format. Flat-file datasets read group values from each group's members rather than by row order, read memberships from a `household_id`-style column when there is no `person_household_id`-style one, reject missing memberships, and no longer declare the previous entity's IDs as their groups.
