`Holder.get_known_periods(branch_name)` lists only the periods that branch reads, and `Simulation` uses it, so values stored only under other branches no longer change what a branch calculates or caches; on-disk storage now parses branch names containing `_`, deletes the periods within a deleted period as in-memory storage does, rejects the keys in-memory storage rejects (years and months anchored mid-month, branch names containing `:`) and leaves files that are not its keys out of `restore`; and `dump_simulation` saves the values the dumped branch reads, with their derived marks.
