A simulation's temporary on-disk storage folder (`openfisca_*`) is now removed once the simulation and every clone, branch or copied disk storage that reads files in it are garbage-collected, or at interpreter exit, instead of being left behind. A clone now stores new on-disk values in a folder of its own, so a clone and its source no longer write over or remove each other's files for a variable both store after cloning. A pickled or copied disk storage, or a forked process, no longer removes files the original still reads, and a disk storage no longer removes the folder containing its own, such as a folder the caller chose as `_data_storage_dir`.
