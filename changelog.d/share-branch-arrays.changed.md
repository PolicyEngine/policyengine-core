`Simulation.get_branch` no longer copies the simulation's cached arrays into each branch: a branch holds read-only views of them, so creating one allocates no array data and results are unchanged (one policyengine-us Enhanced CPS year fell from 48 GB to 8 GB of peak memory). Writing in place into an array a branch inherited from its parent now raises `ValueError` instead of changing the branch's private copy; `Simulation.clone()` still copies every array.
