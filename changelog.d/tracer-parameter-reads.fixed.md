`FullTracer` now records parameter reads in yearly formulas: the parameter tree is pointed at the tracer when `simulation.trace` is set instead of lazily inside `_run_formula`, after `defined_for` and `adds`/`subtracts` evaluation had already read the yearly node (#541). The at-instant cache keeps plain nodes and wraps one for tracing on each access, so switching tracing or swapping branch tracers rebuilds nothing. Scale and bracket reads (`p.rates.calc(x)`, `p.max[children]`) are recorded at their node too (#542). Parameter-backed `adds`/`subtracts` lists and uprating factors, which the core resolves outside the formula, are recorded on the variable's trace node as well, and a nested branch calculation no longer relabels the parameter reads its caller makes after it returns.
