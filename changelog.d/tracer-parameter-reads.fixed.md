`FullTracer` now records parameter reads in yearly formulas: the parameter tree is recast for tracing when `simulation.trace` is set (and its at-instant caches cleared) instead of lazily inside `_run_formula`, after `defined_for` and `adds`/`subtracts` evaluation had already cached the yearly node untraced (#541). Scale and bracket reads (`p.rates.calc(x)`, `p.max[children]`) are recorded at their node too (#542).
