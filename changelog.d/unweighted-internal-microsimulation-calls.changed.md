`Microsimulation.calculate`, `calculate_add` and `calculate_divide` now default to `use_weights=None` and `decode_enums=None`: a call made while another of these calls runs in the same `contextvars` context, or a context copied from it (core's own reads, and formula code that calls these methods or `calculate_dataframe` directly), gets a plain NumPy array with enum codes instead of a weighted `MicroSeries` with member names, so internal reads no longer build weights, while other calls are weighted as before.
