Keep the record of `set_input` values (`Simulation._user_input_keys`) in step with storage, so `apply_reform` and `to_input_dataframe` no longer treat a formula result, or another simulation's input, as an input: `delete_arrays` drops the entries for the values it deletes, `clone` (so also `get_branch`) gives the copy its own record, values a custom `set_input` handler calculates are not recorded, `subsample` records only what it stores, and each entry names the period storage keys the value under (eternity for an eternal variable).
